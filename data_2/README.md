## Cleaned Data

This folder contains cleaned data used for experiments and final trading analysis.

- `agent/` and `futures/` contain data cleaned using the **volume rule**.  
  These files are kept for experimentation only and are not used in the final trading analysis.

- `agent_right/` and `futures_right/` contain data cleaned using the **agent rule**.  
  These files are used for the final trading analysis.

- `result/` contains the PnL plot, position plot, and detailed trading information generated by the trading strategy.

For more details on the difference between the **volume rule** and the **agent rule**, see `demo2_clean_data`.

For a more concrete description of the cleaned data structure and examples, see `demo3_data_display`.
