## Notebooks

This folder contains Jupyter notebooks for exploration, analysis, and prototyping.

- `demo1_explore_data`: explores the raw futures data and agent data.
- `demo2_clean_data`: cleans the raw data and saves the processed files.
- `demo3_data_display`: displays and checks the cleaned data.
- `demo4_price_pnl`: calculates and visualizes the agent's PnL.
- `demo5_tick`: introduces the project objective and tests a simple trading rule to build intuition.
- `demo6_features`: constructs and validates state variables.
- `demo7_trading`: implements the `regime_fixed` trading rule and illustrates its logic and results. This gives the result of the project.
