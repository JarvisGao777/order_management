## Raw Data

This folder contains raw futures data and agent data.

### Futures Contract Month Codes

Futures contract symbols use standard month codes:

| Code | Month |
|---|---|
| F | January |
| G | February |
| H | March |
| J | April |
| K | May |
| M | June |
| N | July |
| Q | August |
| U | September |
| V | October |
| X | November |
| Z | December |
